# Photos for the brand site

`index.html` looks for these seven photos in this folder:

| File | Where it appears |
| --- | --- |
| `hero.jpg` | Top of the page (model in a navy graphic tee) |
| `tees.jpg` | Graphic Tees category card, Drop stories |
| `rack.jpg` | Shirts category card and feature block |
| `jeans.jpg` | Jeans category card and feature block |
| `linen.jpg` | Linen category card and feature block |
| `folded.jpg` | Graphic Tees feature block |
| `shirts.jpg` | Final call-to-action background |

Until they're added, the page shows styled placeholders instead, so nothing looks broken.
To add them on github.com: open this `images` folder → **Add file → Upload files** → drag the photos in → **Commit changes**.
Netlify republishes the site automatically.
